Sobre mí

Desarrollador de software y estudiante de segundo año de Desarrollo de Aplicaciones Web (DAW) en Oviedo. Mi especialización abarca la arquitectura de sistemas backend robustos en Java con Spring Boot y PHP, el desarrollo frontend reactivo con Angular y TypeScript (Signals, Standalone Components), y el diseño y optimización de bases de datos relacionales en PostgreSQL sobre contenedores Docker.

Apasionado por el análisis y tratamiento de datos mediante Python (NumPy, Pandas), la automatización CI/CD y las buenas prácticas de ingeniería de software: arquitectura limpia, pruebas de API y calidad continua.

Plataforma integral para la gestión interna y venta online de Floristería Labajo. Unifica un portal web intuitivo para clientes con un robusto sistema de administración para el seguimiento de pedidos, control de stock de flor fresca y logística de entregas.

Airport SQL Data Analysis

Exploración analítica y consultas relacionales avanzadas sobre base de datos de aviación comercial y reservas de vuelos en PostgreSQL.
